# UI 01: 品質ゲートと回帰基準

## 状態

計画済み・未実装

## 依存関係

- 基準PR #139

## 目的

後続のUI改修が公開URL、初期フィルター、集計結果、認可境界を変えていないことを、PRごとに自動確認できる状態にする。

## 変更対象

- GitHub Actionsによるテスト・Lint・型チェック・本番ビルド
- ユーザー指定の報告項目を含むPRテンプレート
- 公開パス、旧共有リンク、タブ公開範囲、ランキング初期条件のcharacterization test
- Desktop / Tablet / Mobile、Light / Darkの基準画面記録

## 対象外

- UIの見た目や操作フローの変更
- API、DB、集計ロジックの変更
- 新しいE2Eフレームワークの大規模導入

## 互換条件

- 公開API、URL、環境変数、DBスキーマ、localStorageキーを変更しない
- 武将・兵種・武器・品物ランキングの全期間／最低10回という初期条件を維持する
- `/metrics`、`?tab=swi` など既存共有リンクの復元を維持する

## 受入条件

- PRで `npm test`、`npm run lint`、`npx tsc --noEmit`、`npm run build` が自動実行される
- 公開／管理者タブ境界と主要URLに回帰テストがある
- 主要画面の基準画像と撮影条件が文書化される
- ランタイムの表示と入出力に差分がない

## 確認方法

- ローカルの全検証コマンド
- GitHub ActionsとVercel Preview
- 1440 / 1024 / 768 / 390pxでの目視確認

## ロールバック

追加するWorkflow、テンプレート、テスト、文書のみを戻す。プロダクションコードには触れない。
