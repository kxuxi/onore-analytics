# UI 06: 戦闘履歴の情報階層

## 状態

計画済み・未実装

## 依存関係

- UI 05

## 目的

戦闘履歴カードの重複情報と縦方向の長さを減らし、勝敗、日時、参加者を最初に読み取れるようにする。

## 変更対象

- 勝敗、日時、主要参加者を第一階層へ再配置
- 場所、勢力、装備、補助情報の第二階層化
- Mobileでの詳細展開
- 勝敗の色以外の表現
- 履歴フィルター結果件数との統合

## 対象外

- 履歴の件数、並び順、勝敗判定、参加者、保存形式
- コピー内容、削除対象ID、管理者認可

## 互換条件

- 現在表示される全情報へ到達できる
- 既存の検索・期間・国フィルター結果を維持する
- 履歴カードからの武将・兵種・国詳細遷移を維持する

## 受入条件

- 主要情報がカード冒頭で認識できる
- 二次情報へ1操作以内で到達できる
- Mobileカードの重複表示と平均的な高さが減る
- スクリーンリーダーの読み上げ順が視覚順と一致する

## 確認方法

- 変更前後の代表履歴データ比較
- 履歴フィルター単体テスト
- 勝敗、撤退、欠損データ、管理操作の手動確認

## ロールバック

新しいカード表示だけを既存の履歴マークアップへ戻し、集計・フィルター処理は維持する。
