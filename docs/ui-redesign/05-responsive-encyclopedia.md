# UI 05: 図鑑のモバイル最適化

## 状態

実装・ローカル検証完了（Draft PR）

## 依存関係

- UI 04

## 目的

兵種・武器・品物図鑑のデスクトップ向けテーブルがモバイルで切れる問題を解消し、全情報と詳細導線へ到達可能にする。

## 変更対象

- Desktopの比較テーブル
- Tabletの要約カード＋行展開
- Mobileのカードリスト
- 狭幅用の兵種並び替えコントロール
- 兵種編集権限を含むレスポンシブ操作

## 対象外

- 図鑑データ、列の意味、並び替え規則、編集API
- 詳細ページの構成変更

## 互換条件

- Desktopで現在表示している全列を維持する
- Mobileでもすべての値へ1回の展開または詳細遷移で到達できる
- 管理者だけが編集できる認可境界を維持する

## 受入条件

- 320〜767pxでビューポート全体の横スクロールが発生しない
- DesktopとMobileで同じデータ・順序を表示する
- 並び替えを視覚・テキスト・ARIAで認識できる
- タッチ対象を主要操作44px以上とする

## 確認方法

- 320 / 390 / 768 / 1024 / 1440pxの確認
- DesktopとMobileの値比較
- 管理者／未ログイン双方の操作確認

## ロールバック

モバイルカード表示を外し、既存テーブルを再び全幅で表示する。

## 実装結果

### 変更内容

- 兵種・武器・品物の集計、絞り込み、並び替えを表示から分離し、純粋関数としてテスト可能にした。
- 兵種は広い結果領域で従来の8列表、960px未満の結果領域で要約カードへ切り替えた。
- 武器・品物は広い結果領域で従来の5列表、960px未満で同じカード構成へ統一した。
- カードは兵種の攻撃・防御・雇用、装備の使用回数・勝率を優先表示し、残りの既存項目を1回の展開で表示する。
- 1024px相当では2列、768px以下では1列へ切り替える。320pxでもフィルターを2列に保つ。
- 兵種表へ `aria-sort`、狭幅表示へ同じ状態を共有する並び替えセレクターと昇降順ボタンを追加した。
- 主要な名前リンク、展開、並び替え、フォーム操作を44px以上にした。

### 変更理由

兵種図鑑だけがモバイルで横スクロールと先頭列固定に依存し、右側の値と見出しの対応が分かりにくかった。武器・品物も全項目を常時縦積みにしていたため、比較に必要な値と補足情報の優先順位が曖昧だった。

### 互換性

- 兵種の既存8列、武器・品物の既存5列と表示値を維持した。
- 期スコープ、検索、フィルター、最低使用回数、並び替え規則は変更していない。
- Desktop表とカードは同じ `filtered` / `view` 配列を受け取り、独自の再集計や再ソートを行わない。
- `UnitTab` / `EquipTab` のprops、詳細遷移のcallback引数、URL、API、DB列、管理者操作の境界を変更していない。
- 武器=`equip2`、品物=`equip1` という内部の既存集計対応も変更していない。

### 検証結果

- `npm test`: 33 files / 336 tests 成功
- `npm run lint`: 警告・エラーなし
- `npm run typecheck`: 成功
- `npm run build`: 成功
- Chromium実画面:
  - 320 / 390 / 767 / 768 / 1024 / 1440pxで確認
  - 320〜767pxで `documentElement.scrollWidth === clientWidth`
  - 主要カード操作の最小実測高44px
  - 兵種122件、武器55件、品物127件でDesktop表とカードの名前・順序が一致
  - 兵種の攻撃昇順で先頭0、降順で先頭150になることを確認
  - 兵種カードの展開後に得意兵種・必要能力値・ボーナスを確認

### 残っているリスク

- 未ログイン状態で管理者向け追加・一括インポートが非表示であることは確認した。管理者ログイン後の操作は今回変更していないが、保存を伴う手動確認は行っていない。
- CSS Container Queriesに未対応の古いブラウザーではTabletも従来表へフォールバックする。767px以下はMedia Queryでもカード表示を保証する。
- 一覧専用ではない技術・年数・施設/国宝・特殊攻撃は、従来どおり兵種詳細でのみ表示する。
- SSRとリサイズ時の表示安定性を優先し、表とカードは同じ配列から両方を生成してCSSで切り替える。非表示側はフォーカス・アクセシビリティツリー・描画から外れるが、DOM生成量の削減は後続のPerformance UXで再評価する。
- 兵種の行／カード全体のポインター操作は既存互換のため維持した。キーボードでは同じ遷移先を持つ44pxの兵種名ボタンを利用できる。

## Before / After

- Before: 兵種はモバイルでも8列テーブルを横移動し、現在位置から右側の列を推測する必要があった。
- After: 比較頻度の高い値をカードの先頭へまとめ、補足値は同じカード内の1回の展開で確認できる。
- Before: 兵種と武器・品物で狭幅時の情報構造が異なっていた。
- After: 3図鑑とも「名前 → 主要指標 → 一覧の詳細」の同じ視線順へ統一した。
