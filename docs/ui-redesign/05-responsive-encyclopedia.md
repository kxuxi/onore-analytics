# UI 05: 図鑑のモバイル最適化

## 状態

計画済み・未実装

## 依存関係

- UI 04

## 目的

兵種・武器・品物図鑑のデスクトップ向けテーブルがモバイルで切れる問題を解消し、全情報と詳細導線へ到達可能にする。

## 変更対象

- Desktopの比較テーブル
- Tabletの優先列＋行展開
- Mobileのカードリスト
- 並び替え状態、横スクロールを残す箇所の視覚的な案内
- 兵種編集権限を含むレスポンシブ操作

## 対象外

- 図鑑データ、列の意味、並び替え規則、編集API
- 詳細ページの構成変更

## 互換条件

- Desktopで現在表示している全列を維持する
- Mobileでもすべての値へ1回の展開または詳細遷移で到達できる
- 管理者だけが編集できる認可境界を維持する

## 受入条件

- 320〜767pxでビューポート全体の横スクロールが発生しない
- DesktopとMobileで同じデータ・順序を表示する
- 並び替えを視覚・テキスト・ARIAで認識できる
- タッチ対象を主要操作44px以上とする

## 確認方法

- 320 / 390 / 768 / 1024 / 1440pxの確認
- DesktopとMobileの値比較
- 管理者／未ログイン双方の操作確認

## ロールバック

モバイルカード表示を外し、既存テーブルを再び全幅で表示する。
