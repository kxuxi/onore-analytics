# UI 10: WCAG 2.2 AA対応の強化

## 状態

計画済み・未実装

## 依存関係

- UI 09

## 目的

既存のスキップリンク、ARIA、フォーカス表示、ライブリージョンを基盤に、全ページでWCAG 2.2 AA以上を安定して満たす。

## 変更対象

- 文字4.5:1、非テキストUI 3:1のコントラスト
- フォーカス表示、順序、Sticky要素による遮蔽
- 主要操作44px、最低24pxのターゲット
- Dialog、Tab、Combobox、展開UIのキーボード操作
- 色以外による勝敗・順位・増減表現
- 200%拡大、reduced motion、スクリーンリーダー

## 対象外

- コンテンツの意味、集計値、機能の削除
- 自動監査だけを根拠にした適合宣言

## 互換条件

- マウス／タッチの既存操作を維持する
- ARIA追加によって表示ラベルやフォーム値を変えない
- 自動フォーカスでユーザーの現在位置を不用意に奪わない

## 受入条件

- キーボードのみで全主要導線を完了できる
- フォーカストラップやフォーカス消失がない
- 200%拡大で情報・操作を失わない
- 色を認識できなくても状態を判別できる

## 確認方法

- axeまたは同等の自動監査
- キーボード、VoiceOver、200%拡大、reduced motion
- Light / Dark双方のコントラスト測定

## ロールバック

問題のあるアクセシビリティ属性・スタイルを対象コンポーネント単位で戻す。
