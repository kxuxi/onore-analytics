# UI 11: Performance UX

## 状態

計画済み・未実装

## 依存関係

- UI 10

## 目的

表示データと操作結果を変えず、初期描画、フィルター操作、長い一覧の体感速度と視覚的安定性を改善する。

## 変更対象

- LCP、INP、CLSの変更前後計測
- Skeletonの寸法予約
- 非表示タブと重い分析表示の遅延
- 検索・フィルター更新時の不要な再計算削減
- 長い一覧の段階表示または安全な仮想化
- CSSとクライアントJavaScriptの成果物確認

## 対象外

- 集計方法、データ順序、検索結果の変更
- キャッシュによる古いデータ表示
- 大規模な状態管理・フレームワーク置換

## 互換条件

- 同じ入力には同じ表示値・順序・操作結果を返す
- 更新・共有・戻る操作を維持する
- Loading最適化でスクリーンリーダー通知を増やしすぎない

## 受入条件

- 目標値をLCP 2.5秒、INP 200ms、CLS 0.1以下として計測結果をPRへ記録する
- Skeletonから実データへの不要なレイアウト移動を抑える
- フィルター操作時の長いメインスレッド処理を削減する
- 初回JavaScriptとCSSサイズを悪化させない

## 確認方法

- LighthouseとChrome Performance
- Vercel PreviewでのMobile / Desktop比較
- 代表的な大量データでの操作確認
- 全自動検証と入出力比較

## ロールバック

遅延・メモ化・一覧最適化を施した単位ごとに戻し、既存同期描画へ復帰する。
