# UI 08: 管理画面フォームUX

## 状態

計画済み・未実装

## 依存関係

- UI 07

## 目的

偵察、被弾表、DB登録、設定、兵種編集の入力密度とエラー回復を改善し、誤操作と登録失敗を減らす。

## 変更対象

- 意味単位のFieldset
- 必須／任意、補足、フィールド単位エラー
- 保存中、成功、失敗、重複状態
- 破壊的操作の確認Dialog
- Mobileの主要保存アクション

## 対象外

- API payload、バリデーション規則、権限、削除対象
- DBスキーマ、認証方式
- 管理機能の追加

## 互換条件

- 既存APIへ送るキー・値・順序を維持する
- 管理者以外が変更操作を実行できない状態を維持する
- 失敗時の入力保持とログ／例外情報を減らさない

## 受入条件

- キーボードだけで主要登録フローを完了できる
- エラーの概要と該当フィールドが関連付けられる
- 保存中の二重送信を防ぐ
- 破壊的操作は対象と結果を確認できる

## 確認方法

- 未認証／認証済みの境界テスト
- 成功、通信失敗、入力不正、重複、削除の手動確認
- 実データを使う操作は対象を限定して確認

## ロールバック

フォームの表示・フィードバック部分のみ既存構造へ戻し、API処理は維持する。
