# UI 02: デザイントークンとPage Header

## 状態

実装済み・検証済み

## 依存関係

- UI 01

## 目的

ページごとに異なる見出し、余白、文字サイズ、角丸、影、フォーカス表現を共通基盤へ統一する。

## 変更対象

- spacing、typography、radius、shadow、focus、layout、motion token
- 共通 `PageHeader` コンポーネント
- ランキング、履歴、メタ、図鑑、国、管理画面の見出し
- データ画面と読み物画面で異なる最大コンテンツ幅

## 対象外

- ページ名、タブ順、ルーティングの変更
- 各ページ固有のデータ構造や集計ロジック
- Tailwind CSS、shadcn/ui、Radix UI、Framer Motionの導入

## 互換条件

- DOM上のフォーム名、URL、API呼び出し、表示データを維持する
- 既存のLight / Darkテーマとテーマ保存キーを維持する
- 見出し階層を改善してもユーザー向けラベルは変更しない

## 受入条件

- 全主要ページでタイトル、説明、アクションの位置が一貫する
- 既存色を基準にLight / Dark双方でコントラストを維持する
- 960pxの読み物幅と1200px前後のデータ幅を用途別に適用する
- 意図しないVisual diffがない

## 確認方法

- 全自動検証
- Light / Dark × 4 viewportの画像比較
- 見出しアウトラインとキーボードフォーカスの確認

## ロールバック

共通コンポーネント利用を各画面の既存見出しへ戻し、追加tokenを削除する。

## 実装メモ

- 共通基盤の仕様は `design-system-foundations.md` に記録する
- アプリ名を `h1`、各ページ名を `h2`、ページ内セクションを `h3` とする
- Home と詳細画面は後続 PR の情報設計対象として、この PR では既存表示を維持する
- 既存の 6px / 10px / 14px やブレークポイントは、意図しない表示差分を避けるため
  一括置換しない

## 変更内容

- `app/globals.css`: 色、余白、文字、角丸、影、動き、レイアウトの共通 token を追加
- `components/layout/PageHeader.tsx`: タイトル、説明、メタ情報、操作を扱う共通見出しを追加
- 一覧・分析・管理タブ: 既存タイトルと説明を `PageHeader` へ移行
- `app/page.tsx`: 明示したデータ画面だけを最大 1200px、Home と詳細を 960px に分離
- `docs/ui-redesign/ui-02-after`: Light / Dark、Desktop / Mobile の比較画像を保存

## 変更理由

画面ごとに異なっていたタイトルの大きさ、説明の位置、見出し階層、最大幅を統一し、
後続のフィルター、一覧、詳細画面の改善で同じ基準を再利用できるようにするため。

## 互換性

- URL、タブキー、API、DB schema、環境変数、フォーム名、集計処理は変更していない
- 既存の Light / Dark の色値、テーマ保存キー、ブレークポイントを維持
- 既存のページ名と説明は保持し、DOM の見出し階層だけを整理
- Home、詳細、ログイン、エラー表示は後続 PR の対象として既存実装を維持

- `npm run typecheck`: passed
- `npm run build`: passed

## 残っているリスク

- 管理者だけに表示される登録・データ整理操作は、権限付きの手動確認が別途必要
- Safe Area を含む実ヘッダー高と 60px の固定オフセット差は既存課題として残る
- 色値の変更が必要なコントラスト改善は UI 10 のアクセシビリティ PR で行う
- 未使用 token は後続 PR の段階移行用基盤であり、利用範囲を拡大するときに再監査する
