共通詳細テンプレート適用後の代表画面を、146期・未ログイン状態で記録した。

| ファイル | ビューポート | 対象 |
| --- | ---: | --- |
| `warlord-desktop-1440-dark.png` | 1440 × 1000 | 武将「因幡月夜」 |
| `unit-desktop-1440-dark.png` | 1440 × 1000 | 兵種「剛弓僧兵」 |
| `unit-desktop-1440-light.png` | 1440 × 1000 | 同兵種のLightテーマ |
| `unit-mobile-320-dark.png` | 320 × 1000 | 同兵種の最小確認幅 |

| `nation-desktop-1440-dark.png` | 1440 × 1000 | 国「天下五剣」 |

変更前と同じ対象・期・表示幅で、指標値、Section順、件数、URLを比較した。320pxの兵種タイトル領域は44pxから274pxへ広がり、3行から1行になった。320 / 390 / 768 / 1024 / 1440pxのすべてで横スクロールは発生していない。

勝敗・グラフ色はテーマ用トークンへ移し、背景に対するコントラストを計測した。Lightの勝敗文字は5.74:1 / 5.84:1、Darkは8.98:1 / 6.38:1。グラフ線と勝敗バーも両テーマで4.06:1以上だった。
