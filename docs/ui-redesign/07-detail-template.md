# UI 07: 詳細画面テンプレート

## 状態

計画済み・未実装

## 依存関係

- UI 06

## 目的

武将、兵種、武器、品物、国で異なる詳細画面の構造を、共通の見出し、主要指標、Section、空状態へ揃える。

## 変更対象

- `DetailHeader`、主要指標グリッド、共通Section
- Overview、Trend、Breakdown、関連項目、最近の戦闘の階層
- パンくずと戻る導線
- グラフの文章要約と空状態

## 対象外

- 詳細URL、集計値、グラフ計算、関連項目の順序
- API、DB、ブラウザ履歴スタックの仕様

## 互換条件

- すべての詳細URLと既存共有リンクを維持する
- 表示する値、母数、並び順を変更しない
- 戻る操作と相互リンクの挙動を維持する

## 受入条件

- 5種類の詳細画面で同じ情報階層を利用する
- 主要指標を3〜5件に絞り、残りへ容易に到達できる
- 見出し階層とパンくずが現在地を正しく示す
- 欠損・空・読込・エラー状態が共通化される

## 確認方法

- 各詳細種別の代表データと空状態
- URL直アクセス、相互遷移、戻る操作
- 変更前後の値・順序比較

## ロールバック

共通テンプレートを各詳細画面の既存構造へ戻す。statsとAPIには触れない。
