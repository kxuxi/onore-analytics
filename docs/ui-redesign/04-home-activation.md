# UI 04: ホーム未選択時の価値訴求

## 状態

計画済み・未実装

## 依存関係

- UI 03

## 目的

自分の武将が未選択のときに生じる大きな空白を解消し、初回ユーザーがサービスの価値と次の行動を理解できるようにする。

## 変更対象

- 主CTA「自分の武将を選ぶ」
- 武将ランキング、最近の戦闘への補助導線
- 分析できる内容の簡潔なプレビュー
- 最近選択した武将が安全に取得できる場合の再選択導線
- 検索結果のキーボード操作と空状態

## 対象外

- 選択済みホームの集計値、グラフ、ウォッチリスト仕様
- 新しいAPI取得や会員登録フロー
- localStorageキーの変更

## 互換条件

- 自分の武将の保存・復元方法を維持する
- 選択済みユーザーの表示データと操作を維持する
- CTAは既存の公開画面にのみ遷移する

## 受入条件

- 未選択時にもページの目的と3つ以内の主要行動が分かる
- キーボードだけで武将を検索・選択できる
- 追加ネットワークリクエストを発生させない
- 320px幅でも横スクロールが発生しない

## 確認方法

- 未選択／選択済み／検索結果なしの状態確認
- localStorage復元テスト
- Light / Dark、Desktop / Mobileの画像比較

## ロールバック

未選択時の新しい案内部分だけを既存検索表示へ戻す。
